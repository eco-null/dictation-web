# Dikte Web design

Dikte’s default appearance follows the zinc palette shared by PostReady and OpenUninstaller. The shared dark and light themes use the same controls and layout. Forest Green retains the previous green palette. Steel Blue adds a blue-gray option.

| Role | Dark | Light |
| --- | --- | --- |
| Canvas | `#09090b` | `#f7f7f8` |
| Sidebar | `#101012` | `#fcfcfd` |
| Card | `#18181b` | `#ffffff` |
| Text | `#fafafa` | `#18181b` |
| Primary action | `#fafafa` fill, `#18181b` text | `#18181b` fill, `#fafafa` text |

Inter covers reading and navigation. JetBrains Mono covers the recording timer, shortcuts, status labels and timestamps. Both fonts are served locally, with OFL notices next to the font files.

Hairline borders separate surfaces. Emerald marks readiness, amber marks a paused recording or a condition that needs attention, and red marks active recording or an error. Visible labels communicate the state alongside the color.
